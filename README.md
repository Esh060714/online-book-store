Home Page (indexpage.html)

A visually appealing landing page with a navigation bar for easy access to different sections.

Displays a grid of books pulled dynamically from localStorage.

Each book card includes an image, title, author, price, and a “Buy” button.

About Page (About.html)

Provides a brief overview of the website and its purpose.

Includes information about services and value offered to users.

Contact Page (contactpage.html)

A clean and functional feedback form for users to submit feedback or request articles.

Upon submission, the form validates entries and displays a thank-you message.

Smooth user experience without page reload.

Admin Page (Adminpage.html)

Secured with a hardcoded login (admin/admin123) for demonstration purposes.

Dashboard includes tabs for managing:

Books: Add or delete books.

Members: View a static list of registered members.

Orders: Display a mock list of past orders.

Settings: Option to change the admin password (temporary change in JS).

Functionality via script.js:

Handles admin login, dynamic book loading, book addition/deletion.

Controls tab switching in the admin dashboard.

Stores data in localStorage for persistence across sessions.

Displays books dynamically on the user-facing homepage.
